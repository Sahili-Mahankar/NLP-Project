01 • PROJECT FOUNDATION

Methodology

The project follows the progressive workflow documented in the final report.

Problem Statement

Recruiters and analysts often scan many job descriptions to identify required technical skills. Manual extraction is time-consuming and may miss aliases, abbreviations or multi-word skills.

Objectives

  • Clean and preprocess job-description text.
  • Extract technical skills using multiple NLP approaches.
  • Normalize skill names and assign categories.
  • Provide analytics and a user-facing application.

Statistical & Semantic NLP

TF-IDF highlights informative terms. N-Grams capture multi-word phrases. Embeddings and semantic similarity support context-aware matching.

Named Entity Recognition

Standard NER may miss technical skills. A stronger research-grade evaluation would use manually annotated character-level skill spans.

Error Analysis

  • False positives from generic terms.
  • False negatives for unseen aliases or spelling variants.
  • Partial phrase extraction can produce variants such as “Python programming”.
  • Abbreviations such as ML need normalization.
  • Generic “cloud technologies” should not imply AWS/Azure/GCP unless named.
